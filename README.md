# sadoj.com

Repository für die öffentliche Website von [sadoj-hl.com](https://sadoj-hl.com/).

## Umfang

Dieses Repository ist ausschließlich für die öffentliche Website vorgesehen. Das interne Portal **SADOJNET** gehört nicht hierher.

Die Website-Dateien und Verzeichnisstruktur werden erst ergänzt, nachdem die bestehende öffentliche Website und ihre Auslieferung geprüft wurden. So bleiben vorhandene Seiten und Funktionen erhalten und es werden keine unbelegten Seiten oder Build-/Deployment-Einstellungen eingeführt.

## Deployment

Es sind derzeit keine Build- oder Deployment-Konfigurationen eingerichtet. Insbesondere werden keine automatischen Production-Deployments konfiguriert.

## Noch offen

- Bestehende öffentliche Website und Worker-Auslieferung untersuchen.
- Verifizierte Website-Dateien und -Struktur übernehmen.
- Build-/Deployment-Aufbau ohne Änderung des produktiven Workers festlegen.
- Seitenpfade, Navigation sowie CSS-, JavaScript- und Bildreferenzen prüfen.
- Das neue Portrait von Lucas White nach Bereitstellung der Bilddatei korrekt einbinden.
